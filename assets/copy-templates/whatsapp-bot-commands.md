# WhatsApp Bot Commands - Los Iconos

## !iconos [topic]
Generates posts for Instagram, TikTok, Facebook, Twitter/X
Example: !iconos summer hoodie drop

## !iconos-spanish [topic]
Same as !iconos but forces Spanglish output
Example: !iconos-spanish nueva coleccion otono

## !iconos-urgent [topic]
Flash sale / urgency copy for all platforms
Example: !iconos-urgent last 12 hours summer drop

## !iconos-brief [topic]
Generates a full content brief for one post
Example: !iconos-brief fan feature this week

All commands: Admin only. Powered by claude-haiku-4-5 for fast WhatsApp response times.
